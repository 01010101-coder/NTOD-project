- [x] 2.2 Добавить в `storage/db.py` контекст-менеджер `transaction(conn)`: `BEGIN` на входе, `COMMIT` при нормальном выходе, `ROLLBACK` при исключении с пробросом исключения (решение design.md 3). Проверка: на временной БД (`connect` + `init_db`) вставка строки `trips` внутри `with transaction(conn):` и нормальный выход — строка видна при чтении из того же и из нового соединения (commit); вставка внутри блока, завершающегося `raise ValueError`, — исключение проброшено наружу, строка при чтении отсутствует (rollback) (сценарии «Коммит при успехе», «Rollback при исключении» specs).
