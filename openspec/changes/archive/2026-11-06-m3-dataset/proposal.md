## Why

Веха M3 учит нейросеть предсказывать дефицит на 15/30 минут вперёд, но в проекте
нет ни обучающих примеров (окно истории → таргеты), ни эпохи-продолжения для
честной проверки: `data/taxi.db` — единые 30 дней без тест-продолжения, таблица
`forecasts` пуста, пакета `ml/` и секции конфига `ml:` не существует. Этот change
создаёт фундамент вехи: датасет с гарантиями отсутствия утечки будущего —
главный класс ошибок учебных ML-проектов (план `docs/plan-m3-ml.md` §3–§4, §8).

## What Changes

- Makefile-цель `epoch`: генерация единого 37-дневного прогона мира
  `data/m3_epoch.db` (seed из конфига) существующим CLI `python -m simulator
  --days 37 --db …`; первые 30 дней побитово идентичны `data/taxi.db`
  (детерминизм A7), дни 31–37 — свежее тест-продолжение.
- Разделение эпох в конфиге: train дни 1–28, val 29–30 (хвост train на раннюю
  остановку), test 31–37 — роли дней задаёт датасет, мир один.
- Секция `ml:` в `config.yaml` + `MlCfg` в `common/config.py` (12-я корневая
  секция со значениями по умолчанию — старые конфиги грузятся).
- Новый пакет `ml/`, модуль `ml/dataset.py`:
  - слоистый `RowSource` (протокол «метрики окна + расписание поездок»),
    единственная реализация — `SqliteRowSource(m3_epoch.db)`; слой нужен, чтобы
    M6 подключил источник поверх живого движка без переписывания сборки;
  - сборка окна признаков: `window_hours` (дефолт 6 = 72 пятиминутки) × 17
    признаков на шаг (метрики зоны, календарь sin/cos + выходной, среда,
    «возвращающиеся водители» ret_15/ret_30 из расписания trips);
  - таргеты: точечные бакеты ts+15/ts+30 (pred_requests, pred_free_drivers) и
    метки дефицита по правилу контракта;
  - нормализация: StandardScaler на признаки и отдельные scaler'ы на таргеты,
    fit **только на train**, сериализация в артефакт.
- Тесты анти-утечки (окно не выходит за ts, таргеты из правильных бакетов,
  ret-признак использует только назначенные до ts поездки, scaler fit только
  train) + тесты формы окна и scaler roundtrip.

Не входит (границы §2 плана M3): бейзлайны, модели, обучение, walk-forward,
вкладка «Лаборатория» — следующие changes вехи.

## Capabilities

### New Capabilities

- `ml-dataset`: построение обучающих примеров (окно истории → признаки →
  таргеты → нормализация) из записанной истории SQLite с ролями дней
  train/val/test и гарантиями отсутствия утечки будущего.

### Modified Capabilities

— (симулятор и хранилище используются как есть через существующий CLI;
секция конфига — новая, не изменение требований существующих спек).

## Impact

- Новые файлы: `ml/__init__.py`, `ml/dataset.py`, `tests/test_ml_dataset.py`.
- Изменяемые: `common/config.py` (+`MlCfg`), `config.yaml` (+`ml:`),
  `Makefile` (цель `epoch`), `tests/test_config.py` (набор корневых секций).
- Зависимости: новых нет — numpy, scikit-learn, pandas уже в `.venv`.
- Поведение симулятора, хранилища и веб-сервера не меняется; `data/` и
  `artifacts/` в git не попадают (уже в .gitignore).
