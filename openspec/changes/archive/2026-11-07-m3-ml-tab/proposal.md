# Proposal: m3-ml-tab — вкладка «Лаборатория ML»

## Why

Веха M3 обучила обе сети и заполнила `forecasts` (4 `model_version` × 24 120
строк walk-forward), но результат виден только в stdout-таблице CLI и
JSON-артефактах: «факт vs прогноз» из ТЗ не существует, ошибку и калибровку не
показать глазами. План M3 (§8 п. 6, `docs/plan-m3-ml.md`) завершает веху
первым ML-экраном — вкладкой «Лаборатория»: пользователь видит прогнозы против
факта, сводную таблицу «наив-1 / наив-2 / MLP / LSTM», ошибки и калибровку без
чтения файлов.

## What Changes

- Таб-бар «Город / Лаборатория» в существующей странице: переключение видимости
  секций без перезагрузки; поведение города (карта, слайдер, графики, WS) не
  меняется и переживает уход на другую вкладку и возврат.
- Четыре REST-эндпойнта поверх статичных данных (без WS): `GET /api/ml/models`
  (список моделей с кривой loss из артефактов и наивами из `forecasts`),
  `GET /api/ml/forecasts` (строки прогнозов, соединённые с фактом той же БД),
  `GET /api/ml/summary` (сводная метрик из последнего `artifacts/summary-*.json`),
  `GET /api/ml/errors` (остатки, гистограмма, ошибка по часу суток — считает
  сервер).
- Вкладка «Лаборатория»: панель модели (версия, arch, окно, мини-график loss),
  сводная таблица 4 строк, канвас «факт vs прогноз» с селекторами
  зона/горизонт/модель/таргет и полосой `deficit_prob > 0.5`, блок ошибок
  (остатки по времени, гистограмма, по часу суток), калибровочный график.
- `charts.js` обобщается переиспользуемым multiline-хелпером; стиль —
  существующая тёмная палитра; сборка по-прежнему отсутствует.
- Тесты: эндпойнты через TestClient на временных фикстурах (мини-эпоха SQLite +
  мини-артефакты), проверка статики; ручной браузерный дым по чек-листу.

Не входит (границы §2 плана M3): seek-связка вкладок (миры сервера и эпохи
различаются до M5/M6), WS для ML-данных, ветки будущего и вкладка «Сравнение»
(M6), экран параметров обучения (M5), какие-либо изменения мира и моделей.

## Capabilities

### New Capabilities

- `web-ml-tab`: вкладка «Лаборатория» — REST `/api/ml/*` поверх БД эпохи и
  артефактов обучения плюс фронтенд: список моделей с loss, сводная таблица
  метрик, «факт vs прогноз», ошибки, калибровка; таб-бар с сохранением
  поведения города.

### Modified Capabilities

— нет: требования `web-city-ui` (карта, машины, слайдер, графики, часы) не
меняются — вкладка добавляет переключатель видимости, не трогая контракт
воспроизведения.

## Impact

- Код: `app/server.py` (4 эндпойнта, параметр `artifacts_dir` у `create_app`),
  `app/static/{index.html, app.js, charts.js, style.css}`,
  `tests/test_web_ml_tab.py` (новый); возможна минимальная правка
  `tests/test_web_server.py` (страничный тест, если он фиксирует структуру
  страницы).
- Данные (только чтение): `data/m3_epoch.db` (`forecasts` 96 480 строк,
  `zone_metrics_5min`), `artifacts/` (`summary-*.json`, `<model>/metrics.json`,
  `<model>/loss.json`).
- Зависимости: новых нет (FastAPI/starlette уже используются).
- Конфиг: новых ключей нет — БД эпохи берётся из существующего `ml.db`
  (change `m3-dataset`); каталог артефактов — cwd-конвенция `artifacts/`
  CLI обучения, для тестов переопределяется параметром.
