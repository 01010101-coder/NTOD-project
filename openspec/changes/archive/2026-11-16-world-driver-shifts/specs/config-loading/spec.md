## ADDED Requirements

### Requirement: Секция смен drivers.shifts

Модель секции `drivers` SHALL содержать вложенную подсекцию `shifts` с полями:

| поле | тип | дефолт |
|---|---|---|
| `enabled` | bool | `false` |
| `online_share.weekday` | список ровно из 24 float, каждый в (0, 1] | профиль будней ниже |
| `online_share.weekend` | список ровно из 24 float, каждый в (0, 1] | профиль выходных ниже |

Элемент `h` списка — доля парка `drivers.count` на смене в момент `h:00`. Профили по умолчанию — стартовые значения, калибруются отдельно:

- будни: `[0.40, 0.35, 0.33, 0.33, 0.33, 0.40, 0.55, 0.70, 0.80, 0.80, 0.75, 0.70, 0.70, 0.70, 0.70, 0.75, 0.80, 0.85, 0.85, 0.80, 0.72, 0.65, 0.55, 0.45]`;
- выходные: `[0.50, 0.45, 0.40, 0.35, 0.33, 0.33, 0.40, 0.50, 0.60, 0.65, 0.70, 0.70, 0.70, 0.70, 0.70, 0.72, 0.75, 0.80, 0.80, 0.78, 0.72, 0.68, 0.62, 0.55]`.

Конфиг без подсекции `shifts` и конфиг с частью полей SHALL загружаться, недостающие поля берутся из дефолтов. Неизвестные ключи внутри `shifts` и `online_share` SHALL отклоняться с путём до ключа. Профиль не из 24 значений или значение вне (0, 1] SHALL отклоняться ошибкой валидации. Эталонный `config.yaml` SHALL содержать подсекцию со значениями, равными дефолтам, в том числе `enabled: false`.

#### Scenario: Старый конфиг без подсекции

- **WHEN** загружается конфиг, где `drivers` задан как `{count: 380, wait_limit_min: 6}`
- **THEN** загрузка успешна, `drivers.shifts.enabled` равно `false`, профили равны дефолтным

#### Scenario: Частичная подсекция

- **WHEN** загружается конфиг с `drivers.shifts: {enabled: true}`
- **THEN** `enabled` равно `true`, `online_share.weekday` и `online_share.weekend` равны дефолтным профилям

#### Scenario: Профиль неверной длины отклоняется

- **WHEN** конфиг содержит `drivers.shifts.online_share.weekday` из 23 значений
- **THEN** загрузка завершается ошибкой валидации с путём до `online_share.weekday`, конфигурация не создана

#### Scenario: Доля вне диапазона отклоняется

- **WHEN** профиль содержит значение `0` или `1.2`
- **THEN** загрузка завершается ошибкой валидации, конфигурация не создана

#### Scenario: Неизвестный ключ отклоняется

- **WHEN** конфиг содержит `drivers.shifts.online_share.holidays`
- **THEN** загрузка завершается ошибкой с путём `drivers.shifts.online_share.holidays`
