## ADDED Requirements

### Requirement: Лента таймлайна

Сервер SHALL отдавать `GET /api/deficit-timeline` для активного мира: `start` (ISO первого окна), `step` (минут), `zones`, и массивы по закрытым окнам без пропусков — `counts` (число зон в дефиците по правилу контракта), `requests` (заказы по городу), `rain` (0/1).

#### Scenario: Лента совпадает с метриками

- **WHEN** клиент запрашивает ленту и `/api/metrics`
- **THEN** для каждого окна общего префикса `counts`, `requests` и `rain` совпадают с пересчётом по строкам метрик

## MODIFIED Requirements

### Requirement: Снимок мира

Сообщение `snapshot` SHALL содержать в `env.deficit` список флагов дефицита по зонам для последнего 5-минутного окна, закрытого к минуте снимка, или `null`, если ни одно окно ещё не закрыто.

#### Scenario: Кайма видна сразу после seek

- **WHEN** клиент делает seek на минуту 400
- **THEN** `env.deficit` равен дефициту зон окна [395, 400) по метрикам
