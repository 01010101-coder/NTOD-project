## MODIFIED Requirements

### Requirement: Ответ сравнения веток

Каждая ветка ответа `/api/ml/compare` SHALL содержать `tariff_mix` — распределение зона-бакетов тест-недели по тарифу `[{mult, count}]` по возрастанию `mult` (у отсутствующей ветки — пустой список). Вкладка «Сравнение» SHALL показывать его кольцевой диаграммой в карточке мира вместе с долей окон с повышенным тарифом.

#### Scenario: Видно, какие ступени работали

- **WHEN** в мире C тариф повышался ступенями ×1.15, ×1.30 и ×1.50
- **THEN** кольцо карточки C содержит три сегмента с числами срабатываний, а в центре — доля окон с тарифом выше ×1.00
