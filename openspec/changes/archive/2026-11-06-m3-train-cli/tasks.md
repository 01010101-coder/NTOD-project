## 1. Цикл обучения (`ml/train.py`)

- [x] 1.1 Подготовка данных обучения: функция собирает примеры из БД эпохи
  (`SqliteRowSource` + `collect_examples` по ролям из `ml:` конфига и
  `world_start`), обучает `DatasetScalers` на train-роли, нормализует все
  роли, считает `deficit_pos_weight` по train-меткам; пустая роль train или
  val — понятный `ValueError` до построения сети. Проверка: unit-тест на
  синтетической мини-БД (паттерн фикстур `tests/test_ml_dataset.py`): роли не
  пусты, формы массивов соответствуют контракту `Examples`; пустая роль —
  ошибка с сообщением.
- [x] 1.2 Обучение одной архитектуры: `set_global_seed(ml.seed)` →
  `build_model` → ручной батчинг перестановками из
  `np.random.default_rng(ml.seed)` → `MultitaskLoss` + Adam (`ml.lr`,
  `ml.batch_size`), ранняя остановка по val total (строгое улучшение,
  `ml.patience` подряд, кап `ml.max_epochs`), лучшее состояние — глубокая
  копия state_dict. Проверка: тесты на мини-эпохе с закономерностью —
  train-loss последней эпохи меньше первой; при малом `patience` и большом
  `max_epochs` обучение останавливается раньше капа; после ухудшения val
  сохраняется состояние лучшей эпохи.
- [x] 1.3 Артефакты версии модели: каталог `artifacts/{arch}-v1-{дата}/` с
  `weights.pt` (`{arch, state_dict, ml_cfg: model_dump()}`), `scalers.pkl`,
  `loss.json` (компоненты train/val по эпохам), `metrics.json` (лучшая эпоха,
  best_val-компоненты, pos_weight, n_train/n_val, снимок `ml_cfg`, seed,
  wall_sec); существующий каталог — отказ до обучения. Проверка: тест — все
  четыре файла созданы и читаются; восстановление сети из `weights.pt` +
  снимка даёт побитово те же выходы на фиксированном батче; повторный вызов в
  занятый каталог — ошибка.
