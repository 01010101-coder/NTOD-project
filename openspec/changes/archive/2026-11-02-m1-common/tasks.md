## 1. timeutil: ISO-преобразования (`to_iso` / `from_iso`)

- [x] 1.1 Создать `common/timeutil.py` с функцией `to_iso(dt) -> str`: усечь секунды и микросекунды входного наивного `datetime` до `0` и отформатировать в «YYYY-MM-DD HH:MM:SS»; docstring на русском, идентификаторы на английском (решения design.md 2, 8). Проверка: `.venv/bin/python -c "from datetime import datetime; from common.timeutil import to_iso; print(to_iso(datetime(2026, 3, 10, 9, 7, 31, 500_000)))"` выводит `2026-03-10 09:07:00`.
- [x] 1.2 Добавить в `common/timeutil.py` функцию `from_iso(s) -> datetime`: строгий разбор `datetime.strptime(s, "%Y-%m-%d %H:%M:%S")`; на строке не того формата — `ValueError` с указанием ожидаемого формата (решение design.md 3). Проверка: `.venv/bin/python -c "from common.timeutil import from_iso; print(from_iso('2026-03-10 09:07:00'))"` возвращает корректный `datetime`; `.venv/bin/python -c "from common.timeutil import from_iso; from_iso('2026-03-10T09:07:00')"` падает с `ValueError`.
- [x] 1.3 Создать `tests/test_timeutil.py`: roundtrip ISO (`to_iso(from_iso(s)) == s` и `from_iso(to_iso(dt)) == dt` с усечёнными секундами; параметризация: обычная дата, `23:59`, `00:00`, 1 января, 29 февраля високосного 2028); отбрасывание секунд/микросекунд; отказ на некорректных строках (`T`-разделитель, только дата, пустая строка, мусор) — сценарии «Roundtrip ISO», «Секунды и микросекунды отбрасываются», «Некорректный текст отклоняется» из specs. Проверка группы: `.venv/bin/python -m pytest tests/test_timeutil.py -q` — все тесты группы зелёные.

## 2. timeutil: арифметика минут и 5-минутные бакеты

- [x] 2.1 Добавить в `common/timeutil.py` функцию `add_minutes(dt, n) -> datetime`: `dt + timedelta(minutes=n)` с усечением секунд/микросекунд результата; отрицательные `n` разрешены (решение design.md 4). Проверка: `.venv/bin/python -c "from datetime import datetime; from common.timeutil import add_minutes; print(add_minutes(datetime(2026, 3, 10, 9, 58), 5), add_minutes(datetime(2026, 3, 10, 23, 59), 2), add_minutes(datetime(2026, 3, 10, 10, 0), -15))"` выводит `2026-03-10 10:03 2026-03-11 00:01 2026-03-10 09:45`.
- [x] 2.2 Добавить в `common/timeutil.py` функцию `bucket5(ts) -> datetime`: метка начала 5-минутного интервала через модуль минут (`replace(minute=minute - minute % 5, second=0, microsecond=0)`), возврат наивного `datetime` (решение design.md 5). Проверка: `.venv/bin/python -c "from datetime import datetime; from common.timeutil import bucket5, to_iso; print(to_iso(bucket5(datetime(2026, 3, 10, 10, 7, 31))))"` выводит `2026-03-10 10:05:00`.
- [x] 2.3 Дописать `tests/test_timeutil.py`: границы минут (`:00`–`:04 → :00`, `:05`–`:09 → :05`, `:55`–`:59 → :55`), переход часа (`10:56`, `10:59 → 10:55`; `11:00`, `11:01 → 11:00`), переход полуночи и суток (`23:58:31 → 23:55` того же дня; `00:03 → 00:00` своего дня), `add_minutes` через час, полночь, месяц и год; метка бакета — валидный ISO-текст через `to_iso` — сценарии «Прибавление в пределах часа», «Переход через час и полночь», «Границы минут внутри часа», «Переход часа», «Переход полуночи и суток» из specs. Проверка группы: `.venv/bin/python -m pytest tests/test_timeutil.py -q` — все тесты timeutil зелёные, включая новые бакет-тесты.
