- [ ] 4.2 Реализовать `tick()`: один проход по занятым по возрастанию `id`, `remaining_min -= 1`; исчерпание у `TO_PICKUP` → посадка (`ON_TRIP`); исчерпание у `ON_TRIP` → высадка: `FREE`, `zone = dest` из плана поездки, `trip_id = None`; возврат списка пар `(driver_id, зона_высадки)` по возрастанию `driver_id`; переход ровно один за тик (правило «минимум 1 минута», §10.5; design.md, решение 6). - [ ] 4.3 Проверить порядок высадок нескольких водителей за один тик и постоянство суммы счётчиков: два водителя завершают поездки в одной минуте → пары по возрастанию `id`; вдоль цикла `sum(free) + sum(busy) == count` (спека «Высадки одной минуты по возрастанию id» и «Сумма счётчиков постоянна»).
