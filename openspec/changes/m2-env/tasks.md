## 2. Суточные розыгрыши advance_day: дождь и surge-инъекции (§3.6)

- [x] 2.1 Реализовать в `advance_day` розыгрыш дождя: раз в день Bernoulli `cfg.weather.rain_day_chance` (`rng.random() < шанс`); при успехе — эпизод: час старта `rng.integers(episode_start_h[0], episode_start_h[1] + 1)` (замкнутый 6..22), длительность `rng.integers(episode_duration_h[0], episode_duration_h[1] + 1)` ч (1..3); эпизод — абсолютный интервал `[старт, старт + длительность)` от 00:00 разыгранных суток, без усечения полуночью (design.md, решения 2 и 6). Проверка: `.venv/bin/python -c` со сценарием «день без дождя» (`rain_day_chance = 0.0` → эпизод не разыгран) — состояние среды это отражает, rng вызван только на Bernoulli
- [x] 2.2 Реализовать в `advance_day` розыгрыш инъекции после дождя (порядок §3.6: дождь, затем инъекция): Bernoulli `cfg.pricing.surge_injection.day_chance`; при успехе — зона `rng.integers(0, len(cfg.city.zones))`, старт — целая минута `rng.integers(0, 1440)` («U(сутки)»), длительность `rng.integers(duration_min[0], duration_min[1] + 1)` мин (30..60), множитель `rng.uniform(multiplier[0], multiplier[1])` (U(1.2–1.6)); при неуспехе Bernoulli параметры не разыгрываются (design.md, решение 6). Проверка: `.venv/bin/python -c` с `day_chance = 1.0` и фиксированным seed — состояние содержит ровно одну зону с окном длительности 30–60 мин и множителем в [1.2, 1.6]
